✨ 核心特性

🔇

本地离线识别

Whisper 本地运行，零成本、无需联网、隐私完全保护，适合敏感场景使用

⚡

VAD 智能断句

WebRTC 静音检测，自动识别说话起止，无需手动操作，体验流畅自然

📝

长语音支持

自动分块处理，突破 30 秒限制，支持长时间连续语音输入

☁️

云端高精度

一键切换七牛云 ASR，识别精度提升至 ~97%，适合追求极致准确率的场景

💰

成本可控

本地零成本 vs 云端 ¥0.005/10秒，日常使用本地模式，重要场景切换云端

⌨️

快捷键支持

空格键录音、Ctrl+M 切换模式、Ctrl+Enter 强制识别、Esc 取消，高效操作

🚀 快速开始

# 克隆仓库 git clone https://github.com/lilexi-bot/voice-input-method.git cd voice-input-method # 安装依赖 pip install -r requirements.txt # 运行 python main.py # Demo 演示模式（需要 sample.wav） python main.py --demo

首次运行会自动下载 Whisper 模型（约 140MB）
