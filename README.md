# Voice Input Method - 语音输入法

七牛云 × XEngineer 暑期实训营 · 题目一

> 一款基于 Whisper 的智能语音输入法 Demo，支持 VAD 连续识别、长语音处理、本地离线运行。

## 🎯 功能特性

- 🎤 **VAD 连续识别**：采用 WebRTC VAD 静音检测，说话自动开始、停顿时自动结束
- 🎯 **Whisper 本地识别**：完全离线运行，无需上传音频，保护隐私
- 📝 **长语音支持**：自动分块处理，突破短语音限制
- 🔧 **智能纠错**：基础拼音纠错 + 标点恢复 + 格式规范化
- 💨 **低延迟响应**：优化录音流程，快速输出识别结果
- 📋 **一键复制**：识别结果可直接复制使用
- ⚡ **快捷键支持**：空格键录音、Ctrl+Enter 强制识别、Esc 取消

## 📊 技术方案

| 模块 | 技术选型 | 说明 |
|------|----------|------|
| 语音识别 | OpenAI Whisper (base) | 本地离线，中英文准确率 95%+ |
| 静音检测 | WebRTC VAD | 自动检测语音起止 |
| 录音采集 | PyAudio | 16kHz 采样率优化 |
| 文本纠错 | 正则规则 + 标点模型 | 基础纠错，无需网络 |
| UI 界面 | Tkinter | Python 标准库，零依赖 |
| 部署方式 | 本地运行 | 完全离线 |

## 🔧 环境要求

- Python 3.9+
- macOS / Windows / Linux
- 麦克风设备
- ~500MB 磁盘空间（模型 + 依赖）

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行程序

```bash
python main.py
```

首次运行会自动下载 Whisper 模型（约 140MB）。

### 3. 使用方法

| 操作 | 方式 |
|------|------|
| 开始/结束录音 | 按住空格键，说完松开 |
| 强制识别 | Ctrl + Enter |
| 取消录音 | Escape |
| 复制结果 | 点击「复制」按钮 |

## ⚙️ 核心技术原理

### 1. VAD (Voice Activity Detection) 连续识别

```
┌─────────────────────────────────────────────────────────────┐
│  音频帧 (30ms)                                              │
│       ↓                                                     │
│  WebRTC VAD 检测 ──→ 是语音？                               │
│       ↓                    ↓                                │
│      否                    是                               │
│       ↓                    ↓                                │
│  累积静音帧           触发录音                               │
│       ↓                    ↓                                │
│  超时判定 ←──────── 停止说话？                              │
│       ↓                                                     │
│  结束录音 → 输出识别结果                                     │
└─────────────────────────────────────────────────────────────┘
```

### 2. 长语音分块处理

当音频超过 30 秒时，自动分块识别并拼接：

```
长音频 (90s)
    ↓
┌───────┬───────┬───────┐
│ 0-30s │30-60s │60-90s │  (每块 30s)
└───┬───┴───┬───┴───┬───┘
    ↓       ↓       ↓
  识别    识别    识别
    ↓       ↓       ↓
  结果1  结果2  结果3
    └───────┴───────┘
          ↓
    结果1 + 结果2 + 结果3
```

## ⚠️ 常见问题

**Q: 提示"麦克风权限被拒绝"？**
> Windows: 设置 → 隐私 → 麦克风 → 允许应用访问
> macOS: 系统偏好设置 → 安全性与隐私 → 隐私 → 麦克风

**Q: 模型下载失败？**
> 检查网络连接，或手动下载：https://github.com/openai/whisper

**Q: 识别不准？**
> 1. 确保环境安静
> 2. 说话清晰、语速适中
> 3. 尝试靠近麦克风
