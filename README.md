## 🚀 快速开始

### 环境要求

- Python 3.9+
- 麦克风设备
- ~500MB 磁盘空间

### 安装运行

```bash
# 克隆仓库
git clone https://github.com/lilexi-bot/voice-input-method.git
cd voice-input-method

# 安装依赖
pip install -r requirements.txt

# 运行
python main.py
```

首次运行会自动下载 Whisper 模型（约 140MB）。

### Demo 演示模式

```bash
# 需要准备 sample.wav 音频文件
python main.py --demo
```

## 📖 使用指南

### 操作方式

| 操作 | 方式 |
|------|------|
| 开始/结束录音 | **按住空格键**，说完松开 |
| 强制识别 | `Ctrl + Enter` |
| 取消录音 | `Escape` |
| 切换模式 | `Ctrl + M` |
| 复制结果 | 点击 **复制** 按钮 |

### 模式选择

| 场景 | 推荐模式 |
|------|----------|
| 隐私敏感、无网络 | 本地 Whisper |
| 追求更高精度 | 云端七牛云 ASR |
| 长时间输入 | 本地（长语音分块） |

## 📊 性能与成本对比

### 核心指标

| 指标 | 本地 Whisper | 七牛云 ASR |
|------|-------------|------------|
| **准确率** | ~92% | ~97% |
| **延迟** | < 2s (5秒音频) | < 0.5s |
| **网络要求** | ❌ 无需联网 | ✅ 需要联网 |
| **隐私** | ✅ 完全本地 | ⚠️ 音频上传 |
| **单次成本** | ¥0 | ¥0.005/10秒 |
| **100次使用** | ¥0 | ¥0.5 |

### 成本计算示例

```
本地模式：¥0 × 100次 = ¥0
云端模式：¥0.005 × 100次 = ¥0.5

每节省 ¥1 = 可使用云端识别 200 次
```

**建议**：日常使用本地模式，重要场景切换云端复核。

## ⚙️ 配置说明

### 七牛云 ASR 配置（可选）

如需使用云端模式，在 `qiniu_asr.py` 中配置：

```python
QINIU_ACCESS_KEY = "your_access_key"
QINIU_SECRET_KEY = "your_secret_key"
```

获取密钥：https://portal.qiniu.com/user/key

### VAD 参数调整

在 `whisper_recognizer.py` 中调整静音检测灵敏度：

```python
VAD_AGGRESSIVENESS = 3  # 0-3，越高越激进
MIN_SPEECH_MS = 250     # 最小语音时长
MAX_SILENCE_MS = 800    # 静音超时
```

## 🔧 常见问题

**Q: 提示"麦克风权限被拒绝"？**
> Windows: 设置 → 隐私 → 麦克风 → 允许应用访问  
> macOS: 系统偏好设置 → 安全性与隐私 → 隐私 → 麦克风

**Q: 模型下载失败？**
> 检查网络连接，或手动下载：https://github.com/openai/whisper

**Q: 识别不准？**
> 1. 确保环境安静
> 2. 说话清晰、语速适中
> 3. 尝试靠近麦克风

**Q: VAD 触发不灵敏？**
> 调整 `VAD_AGGRESSIVENESS` 参数（0-3）

## 📝 赛题解析

### 评分维度

| 维度 | 本项目方案 |
|------|----------|
| **准确度** | 本地 92% / 云端 97% |
| **易用性** | 空格键录音、VAD 自动断句 |
| **响应速度** | 短语音 <2s，长语音分块处理 |
| **成本** | 本地 ¥0，云端 ¥0.005/10秒 |
| **差异化** | 双模式切换、VAD 连续识别 |

### 设计思考

1. **成本 vs 精度权衡**：本地免费但精度有限，云端付费但精度更高，用户可自主选择
2. **隐私 vs 便利**：敏感场景用本地，日常场景可用云端
3. **离线 vs 在线**：本地模式无网络依赖，适应多种场景
